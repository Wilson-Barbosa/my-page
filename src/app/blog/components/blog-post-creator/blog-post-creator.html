This is my first post here and I would like to talk about my personal experience with desktop-linux. As it's the case with many people I was always a Windows user. Without a doubt, windows it's a great operating system, it has many out-of-the-box features that make it the de facto desktop operating system for most users. The reasons for this dominance are many, and in my opinion the large amount of compatipatible applications is the primary reason for its success. Because windows is made to satify the need of a large consumer base it ships with many apps that a user might not want or need initially. You pay convinience of use with bloat and potiatilly the overuse of resources of your machine. Once I started coding windows became quite frustrating. My PC is a low-end one, with a hard drive and a quite old CPU, so the the system would freeze and lag A LOT, especially with one or two vscode screens open, language servers running in the background and potentially more than one local server running. This quicly became too much for my machine to handle and a resource-hungry OS like windows didn't help a bit. Things changed a bit when I switched to linux Ubuntu and at first it seemed better, but for my surprise my experience became worse than with windows. That happened because of a feature called memory swapping. Memory swapping allows the OS to use the pc's SSD or hard-drive as temporary memory, effectively extending the available RAM if the latter runs out of space. This can slow down the computer, because IO operations are orders of magnitude slower than RAM operations. First I upgraded my RAM from 8gb to 16gb and while that helped immensilly my experience was not ideal still.Then, I finally found the best OS until now, at least the best one for my needs, a Ubuntu-based distribution called Lubuntu, from which I'm writting this post. Lubuntu provided me the with everything I needed:
  1. An operating system with excellent GUI
  2. Low CPU and memory usage
  3. Fast, lightweight and reliable
  4. Ubuntu-based distro with high app compatibility
 Lubuntu with is similar to windows, more so than ubuntu with the GNOME GUI, but it uses LXQt, a lightweight desktop environment that demands very little of your RAM and CPU. Of course, you don't have animations, smooth transitions and other graphical features that many other desktop environments have. For me this is not a problem and, to be honest, I didn't even notice it until I've read the official docs. In the future I might install even lighter distros, but even now I'm extremely happy to experience freedom and power I haven't felt using other OSs to the point that when I upgrade my current machine I will, most likely, install Lubuntu again. If by any chance you want to experience this distro feel free to install it or try the live version, that runs on any bootable device and it's available at the official website. Have a nice day and God bless!
