For anyone that has ever worked with web development working with CSS can be frustraing to say the least. It has so many exceptions and wierd behaviors that I feel like fighting against it sometimes, to the point of almost being scared of it. Crazy, isn't? But that was the feeling I and maybe other people had.

To "solve" or at at least easy this pain lots of tools, libraries and all types of solutions that either modify or override CSS styling were created. Today I would like to talk about one that is loved by many (including me) and for good reasons: Tailwind CSS.

The official documentation describe it as:

"A utility-first CSS framework packed with classes like flex, pt-4, text-center and rotate-90 that can be composed to build any design, directly in your markup."

That description is accurate and although tailwind is much more than that I like to think of it as just a bunch of pre-written vanilla CSS classes, just like the ones you or me would create. Then I just put the class inside the html and you are done.
